# 🧮 Basic Calculator in C++

A simple calculator built using C++ that performs basic arithmetic operations like addition, subtraction, multiplication, and division.

## Features
- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- User-friendly console interface

## Concepts Used
- C++ Basics
- Variables and Data Types
- Conditional Statements (if-else)
- User Input and Output

## Language
C++
